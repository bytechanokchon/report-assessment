# Report Assessment

## ภาพรวมโปรเจกต์

โปรเจกต์นี้เป็นเว็บแอปพลิเคชันที่พัฒนาด้วย Angular สำหรับนำเข้าข้อมูลจากไฟล์ Excel แสดงผลข้อมูลในรูปแบบตารางและกราฟ รวมถึงค้นหา กรองข้อมูล และส่งออกข้อมูลเป็นไฟล์ Excel เพื่อช่วยให้ผู้ใช้งานสามารถตรวจสอบและวิเคราะห์ข้อมูลได้สะดวกยิ่งขึ้น

## คุณสมบัติของระบบ

- **นำเข้าข้อมูลจาก Excel:** ผู้ใช้สามารถเลือกไฟล์ Excel เพื่อให้ระบบอ่านและนำข้อมูลมาแสดงผลโดยอัตโนมัติ
- **แสดงผลข้อมูลในรูปแบบตาราง:** จัดแสดงข้อมูลจากไฟล์ Excel ในรูปแบบตารางที่อ่านและตรวจสอบได้ง่าย
- **แสดงผลข้อมูลในรูปแบบกราฟ:** นำเสนอข้อมูลในรูปแบบกราฟเพื่อช่วยให้เห็นภาพรวมและแนวโน้มของข้อมูล
- **ค้นหาและกรองข้อมูล:** รองรับการค้นหาข้อมูลจากฟิลด์ต่าง ๆ เช่น วันที่และหมายเลข Invoice
- **ส่งออกข้อมูลเป็นไฟล์ Excel:** ผู้ใช้สามารถส่งออกข้อมูลเพื่อนำไปใช้งานหรือวิเคราะห์เพิ่มเติมได้

## ข้อกำหนดเบื้องต้น

ก่อนเริ่มใช้งานโปรแกรม กรุณาติดตั้งซอฟต์แวร์ดังต่อไปนี้

- [Node.js](https://nodejs.org/en/download)
- Angular CLI

ติดตั้ง Angular CLI โดยเปิด Terminal หรือ Command Prompt แล้วรันคำสั่งต่อไปนี้

```bash
npm install -g @angular/cli
```

## วิธีติดตั้งและเรียกใช้งานโปรแกรม

1. ดาวน์โหลดหรือ Clone Source Code ของโปรเจกต์จาก Repository
2. เปิด Terminal หรือ Command Prompt ในโฟลเดอร์หลักของโปรเจกต์
3. ติดตั้ง Dependencies ที่จำเป็น โดยใช้คำสั่ง

   ```bash
   npm install
   ```

4. เริ่มต้นการทำงานของโปรแกรมด้วยคำสั่ง

   ```bash
   ng serve
   ```

5. เปิดเว็บเบราว์เซอร์และเข้าใช้งานผ่าน URL ต่อไปนี้

   `http://localhost:4200/`

## เทคโนโลยีที่ใช้พัฒนา

- **Angular** — ใช้พัฒนาส่วนติดต่อผู้ใช้งาน (Frontend)
- **TypeScript** — ใช้ในการพัฒนาตรรกะการทำงานของระบบ
- **Tailwind CSS** — ใช้ในการจัดรูปแบบและออกแบบส่วนติดต่อผู้ใช้งาน
- **xlsx** — ใช้สำหรับอ่านและจัดการข้อมูลจากไฟล์ Excel

## หมายเหตุ

- กรุณาติดตั้ง Dependencies ให้เรียบร้อยก่อนเริ่มใช้งานโปรแกรม
- โครงสร้างของไฟล์ Excel ควรเป็นไปตามรูปแบบที่ระบบรองรับ
